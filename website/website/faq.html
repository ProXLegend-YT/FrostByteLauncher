Frequently asked questions

Including the questions people are actually skeptical about.

Legitimacy & safety

Is FrostByte Launcher legit / safe to install?

Yes. FrostByte is free and open source — every line of code is public on GitHub, and every release is built automatically from that public source through GitHub Actions, not hand-assembled or uploaded from somewhere unverifiable. You can read the build logs for any release, or build the app yourself from source if you want full certainty.

Is this affiliated with Mojang or Microsoft?

No. FrostByte is an independent, unofficial project and is not affiliated with, endorsed by, or connected to Mojang Studios or Microsoft in any way. You'll need your own legitimately purchased Minecraft: Java Edition account (Microsoft, Ely.by, or an offline/local profile) to play.

Why does Android warn me before installing?

Because FrostByte isn't distributed through the Google Play Store, Android shows a standard warning for any app installed from an APK file directly — this is normal behavior for open source and independent apps in general, not something specific to FrostByte.

Compatibility & performance

Will it run well on my phone?

It depends heavily on your device's GPU and RAM — Minecraft: Java Edition wasn't built for mobile, and FrostByte translates it to run on Android rather than reinventing it. Devices with at least 4GB RAM and a reasonably modern GPU tend to run best. FrostByte auto-detects your device's capability and adjusts RAM allocation and default settings accordingly, and lets you switch renderers if one performs poorly on your specific hardware.

Which renderer should I use?

Start with the default. If you get crashes or poor performance, try switching between GL4ES, Zink (Vulkan), and LTW in Settings → Video and renderer — different GPUs handle each differently, and there's no single best choice for every device.

Why did the game crash right after I picked a renderer?

Some renderers (particularly Zink/Vulkan) depend on your device's own GPU driver having solid Vulkan support — on GPUs with incomplete drivers, this can crash with no fix possible from the app's side. FrostByte shows a warning before you select a renderer known to be unstable on some devices; switching back to GL4ES or LTW usually resolves it.

Mods & content

Can I install mods?

Yes — Forge, Fabric, and OptiFine can be installed directly, and full modpacks can be searched and installed from CurseForge and Modrinth without leaving the app.

Does it support shaders and resource packs?

Yes, through OptiFine or a compatible mod loader, the same way you'd add them on desktop Minecraft — resource packs and shaders are managed per-instance.

About the project

What's the difference between FrostByte and other Android launchers?

FrostByte is built on the same open source lineage as PojavLauncher and MojoLauncher — it isn't a from-scratch engine. What FrostByte adds on top: world backup/restore, full crash history instead of just the latest report, a low-memory warning system, and ongoing UI and control refinements. It's honest about that lineage rather than pretending otherwise.

How do I report a bug or request a feature?

Open an issue on the GitHub repository. Include your device model and, if possible, a crash report from the in-app Crash History screen — that's exactly what it's there for.
