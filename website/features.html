Rendering

Pick the renderer that fits your GPU

Not every Android GPU handles the same graphics path equally well. FrostByte lets you choose between GL4ES (broadly compatible), Zink/Vulkan (faster on GPUs with solid Vulkan drivers), and the newer LTW renderer built specifically for OpenGL ES 3 devices. If one crashes or runs poorly on your device, switch — no reinstall needed.

  • GL4ES — the safe, broadly compatible default
  • Zink (Vulkan) — faster where the driver actually supports it
  • LTW — a modern OpenGL ES 3 renderer for newer devices
  • Honest in-app warnings before you pick a renderer known to be unstable on some devices

Mods & Modpacks

Forge, Fabric, OptiFine — actually working

Install mod loaders directly, or pull full modpacks from CurseForge and Modrinth without leaving the app. Mods, resource packs, and shaders are managed per-instance, so different worlds can run completely different setups.

  • Forge, Fabric, and OptiFine installers built in
  • Search and install modpacks from CurseForge and Modrinth
  • Per-instance mod and resource pack management

Controls

Controls that are actually yours

Every button — movement, inventory, hotbar, sneak — can be resized, repositioned, and rebound. Layouts can be reset per instance, so a PvP setup and a survival-building setup don't have to fight over one control scheme.

  • Drag-to-reposition, resize, and rebind any control
  • Gamepad and mouse+keyboard support alongside touch
  • Per-instance control layouts
